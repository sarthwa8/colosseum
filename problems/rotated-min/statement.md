# Minimum in Rotated Sorted Array

An array of **distinct** integers was sorted in increasing order, then rotated
right by `k` positions for some `k >= 0` (possibly zero — the array may still
be fully sorted). Find its minimum element.

## Input
- The first line contains one integer `n`.
- The second line contains the `n` rotated array elements.

## Output
A single line with the minimum element.

## Example
Input:
```
7
15 21 36 3 7 9 12
```
Output:
```
3
```
The original sorted array `3 7 9 12 15 21 36` was rotated right by 3.
