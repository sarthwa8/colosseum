# Input Constraints

- The first line contains a single integer `n` with `1 <= n <= 2*10^5`.
- The second line contains exactly `n` **distinct** integers, each in
  `-10^9 <= x <= 10^9`.
- The array is a sorted (increasing) array rotated right by some `k` with
  `0 <= k < n`. `k = 0` (no rotation at all) is valid and must be handled.

Any input satisfying these constraints is valid and must be handled correctly.
An array that is not a rotation of a sorted array of distinct elements is
**not** a valid input.
