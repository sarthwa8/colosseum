# Maximum Subarray Sum

Given an array of integers, find the contiguous non-empty subarray with the
largest sum and print that sum.

## Input
- The first line contains one integer `n`, the number of elements.
- The second line contains `n` space-separated integers.

## Output
A single line containing one integer: the maximum subarray sum.

## Example
Input:
```
9
-2 1 -3 4 -1 2 1 -5 4
```
Output:
```
6
```
The subarray `[4, -1, 2, 1]` has the largest sum, `6`.
