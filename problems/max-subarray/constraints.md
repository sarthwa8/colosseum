# Input Constraints

- The first line contains a single integer `n` with `1 <= n <= 10^5`.
- The second line contains exactly `n` integers separated by single spaces.
- Each element `x` satisfies `-10^4 <= x <= 10^4`.
- The subarray must be non-empty, so an all-negative array has a negative answer
  (the largest single element).

Any input satisfying these constraints is valid and must be handled correctly.
