# Input Constraints

- The first line contains two integers `n m` with `1 <= n, m <= 100`.
- Each of the next `n` lines contains exactly `m` integers, each in
  `-10^9 <= x <= 10^9`.
- Single-row (`n = 1`), single-column (`m = 1`), and `1 x 1` grids are all
  valid, as are tall-and-thin and short-and-wide rectangles.
- Every element must be printed exactly once.

Any input satisfying these constraints is valid and must be handled correctly.
