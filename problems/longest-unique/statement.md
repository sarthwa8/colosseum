# Longest Substring Without Repeats

Given a string, find the length of its longest contiguous substring in which
no character appears more than once.

## Input
A single line containing the string. The line may be empty.

## Output
A single line with one integer: the length of the longest substring without
repeated characters.

## Example
Input:
```
abcabcbb
```
Output:
```
3
```
The longest substrings without repeats are `abc`, `bca`, and `cab`, all of
length 3.
