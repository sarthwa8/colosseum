# Input Constraints

- The first line contains a single integer `n` with `1 <= n <= 10^4`.
- Each of the next `n` lines contains exactly two integers `l` and `r` with
  `-10^9 <= l <= r <= 10^9`.
- Intervals are closed and may be given in any order; they may be nested,
  duplicated, or touching. Touching intervals (`r` of one equals `l` of
  another) must be merged.

Any input satisfying these constraints is valid and must be handled correctly.
