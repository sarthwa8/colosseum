# Input Constraints

- The first line contains a single integer `T` with `1 <= T <= 10^5`.
- Each of the next `T` lines contains exactly four integers `a b c d`.
- `-10^18 <= a, c <= 10^18` and `-10^18 <= b, d <= 10^18` with `b != 0` and
  `d != 0`. **Denominators may be negative.**
- Comparisons must be exact: values of this magnitude lose precision in
  64-bit floating point.

Any input satisfying these constraints is valid and must be handled correctly.
